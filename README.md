# BinFloater · 安卓编码转换悬浮窗

> **这个项目全部由 AI 制作。** 代码、测试、文档都是 AI 写的，人类只负责提需求和真机验收。

一个常驻桌面的小悬浮球。点一下展开面板，把文字转成**二进制 / HEX / Base64 / 摩斯码**，或者把二进制、Base64、摩斯码解回文字——方向自动识别。纯本地转换，不上传任何内容，只申请「悬浮窗」这一个特殊权限。

---

## 它解决什么问题

要跟编码打交道的场景到处都是：CTF 题面里一串 0/1、串口日志里的 hex dump、JWT 里那段 Base64、协议文档里的字节流。想知道这串东西是什么字，通常得切浏览器、开命令行、或者心算 ASCII 表——中间还要把当前内容复制来复制去。

这个工具把这一步压成「点一下悬浮球」：剪切板里是什么就按什么解，面板浮起来直接给结果。反过来，把一段文字转成二进制 / HEX / Base64 / 摩斯码 也是一下的事。

判断方向不用你操心：看起来是 0/1 就按二进制解，看起来是 Base64 就按 Base64 解，看起来是一串 `.` `-` 就按摩斯码解，是普通文字就正向编码。判错了随时手动切，切完它就按你选的来。

| 悬浮球 | 面板 |
|---|---|
| 桌面上的小方块，显示 `01` / `BIN` | 点开后是完整面板：输入框、输出框、状态行、按钮行 |

| 输入 | 输出 |
|---|---|
| `hi` | `01101000 01101001`（二进制）/ `68 69`（HEX 显示档）/ `aGk=`（Base64 档） |
| `01101000 01101001` | `hi` |
| `aGk=` | `hi` |
| `5L2g5aW9` | `你好` |

## 功能

### 核心

- **双向 × 四种编码**：文字 ↔ 二进制、文字 ↔ Base64、文字 ↔ 摩斯码、文字 ↔ HEX。标题栏两个按钮各管一个轴：
  【自动 / 文→码 / 码→文】管方向，【BIN / B64 / 摩斯 / HEX】管编码格式
- **HEX 也能出**：显示格式里的 `HEX` 档把结果按字节十六进制输出（`68 69`），复制和分享都跟着这个格式走
- **五种显示格式**：`8位` 一组 / `4位` 一组 / `连写` / `HEX` / `Base64`，一键循环切换，选择会记住（HEX / Base64 是输出格式；输入侧认 0/1 串和 Base64）
- **点一下读剪切板**：点悬浮球展开面板时，自动把剪切板内容读进来并翻译
- **复制结果**：转好的内容一键回写剪切板
- **分享**：把结果直接发到别的 App
- **转换历史**：最近 20 次转换自动留痕，点一下就回填，不用重新粘贴
- **自动识别方向**：剪切板或手打的内容里是 0/1 串就按「二进制 → 文字」，是 HEX 就按「HEX → 文字」，是 Base64 就按「Base64 → 文字」，是摩斯码就按「摩斯码 → 文字」，否则按当前编码格式正向转。识别结果随时可点方向按钮覆盖

### 编码细节

- **UTF-8 优先**，解不出来依次回退 GBK → Big5 → Latin-1
- 认多种分隔符：空格、逗号、分号、冒号、下划线、短横线、斜杠、竖线，也认完全连写
- 认 `0b` 前缀
- 阈值保护：**少于 16 位不当二进制**；少于 24 位还要求同时含 0 和 1，避免把 `2024` 这种数字误判成二进制
- 上限保护：单次最多处理 20000 位（约 2500 字节），超过会提示而不是卡死
- 解码回退顺序里带控制字符保护：解出来一大半是乱码控制符时，会提示「可能不是二进制」而不是甩一屏方块
- **HEX 双向**：`48 65 6C 6C 6F` / `0x48656C6C6F` / `48656C6C6F` 都认，冒号、逗号、下划线、短横线、空格都算分隔符；判定要求「解出来是正常正文」，所以 `2024` 不会被当年份吃掉、`deadbeef` 也不会被当成十六进制
- **Base64 判定不误伤普通英文**：光看字母表任何 4 个字母都能「解」，所以判据是「解出来的是不是正常文本」——`test`、`HelloWorld` 不会被当成 Base64，中文/emoji 的 Base64 能认出来
- **摩斯码**：字母之间一个空格、词之间 `/`（`HELLO WORLD` → `.... . .-.. .-.. --- / .-- --- .-. .-.. -..`）；国际码表 26 字母 + 10 数字 + 18 个常用标点；解出来一律大写（摩斯本身没有大小写）
- **中文走「中文电码」**：一个汉字 → 4 位数字（历史上中文电报就是这么发的）→ 每位数字 5 个符号，连成 20 符号一个「词」，所以中文真的能按摩斯发出去、也能原样解回汉字（`你好` → 两个 20 符号的词）。内置 7078 字，码表里没有的字（生僻字、emoji、日文）用 `?` 占位，两端都能一眼看出「这里缺了个字」
- **能听**：面板上 `♪ 播放` 把当前摩斯码按标准节奏播出来（点 1 / 划 3 / 符号间 1 / 字母间 3 / 词间 7 单位），速度 10–40 WPM 可调（长按按钮或长按球菜单），全程离线、不读任何音频资源；同时可选震动节拍，静音场合靠手感读码

### 悬浮窗

- 悬浮球可以拖到任意位置，位置会记住（含横竖屏，转屏后自动收回屏幕内）
- 悬浮球只有一个小方块大小（显示 `01` / `BIN`），不挡视线
- **球大小三档 / 不透明度四档**，长按菜单里直接调，调完记住
- **面板可拖动**：拖标题栏把面板挪到顺手的地方，松手后固定，不再跟着球跑（长按菜单里可以解除固定）
- 面板位置跟着悬浮球走，展开时自动对齐到球的右下方，靠边时会自动翻转方向
- **深浅色主题**：跟随系统 / 强制浅色 / 强制深色，三选一
- **四种界面风格**：经典（默认）、简洁卡片、深色科技、Material You。主界面、悬浮球、转换面板、按钮、输入框和历史胶囊共享配色与圆角；切换立即生效，不用重启。风格只在主界面的「界面风格」卡片选择，没有重复的旧预览入口
- **长按悬浮球**弹出快捷菜单：打开面板 / 方向 / 编码 / 球大小 / 球不透明度 / 复制 / 重置位置 / 关闭悬浮窗
- 常驻通知栏（Android 前台服务要求），通知上直接带「打开面板」「关闭」两个按钮
- 主界面的开关和实际运行状态永远一致：服务被杀、被长按关掉后，开关会自动回落
- 主界面可以清空转换历史、重置全部设置

### 更新

- **App 内检查更新，不用梯子**：仓库根有个静态 `version.json`，App 读它拿最新版本号，请求走 jsDelivr / gh-proxy 镜像（国内实测可通），有新版本就直接在 App 里下载并拉起系统安装器
- 打开主界面时顺手查一次（24 小时节流），也可以手动点「检查更新」；自动检查失败不打扰，手动检查才显示失败原因
- 下载的 APK 只存在 App 私有缓存目录，装完即弃；只下载本 App 自己的 APK，不做任何其他网络请求

## 为什么不能自动监听剪切板

这是 Android 的系统限制，不是实现偷懒。

**Android 10（API 29）起，没有输入焦点的应用读剪切板一律返回空。** Android 12 之后 `hasPrimaryClip()` 甚至直接返回 false。能绕过的办法只有三条：

| 方案 | 代价 |
|---|---|
| 抢焦点（本项目的做法） | 读之前得先弹出获得焦点的窗口，会打断当前输入 |
| `READ_LOGS` 权限 | 需要 adb 授权，普通用户装不了 |
| Shizuku | 需要额外装一个 App 并每次重启后重新授权 |

所以这个项目选了第一条，但把它做成**按需触发**：不常驻监听，只有你点悬浮球那一刻才抢焦点读一次。代价是点的那一下会收起当前键盘，换来的是只申请悬浮窗权限、不常驻后台耗电、不读取你没让它读的东西。

## 快速开始

从 [Releases](../../releases) 下载 `BinFloater.apk`，装好后：

1. 打开 App，点「① 授予悬浮窗权限」，在系统设置里允许「显示在其他应用上层」
2. 回到 App，打开「悬浮窗」开关
3. 桌面边缘出现小方块，点它展开面板

面板右上角的 `✕` 只收起面板，小方块还在，随时能再点开；长按 `✕` 才彻底关掉悬浮窗。关掉之后回 App 看，开关会自己回到「关」，状态永远是真实的。

需要 Android 14（API 34）以上。

## 技术上的几个选择

**不用 Gradle。** 这个项目只有 7 个源文件、4 个资源，Gradle 拉依赖动辄几百 MB 还要联网。手工调 `aapt2` / `javac` / `d8` 一条流水线下来，从零到出包 3 秒。

**编解码核心零 Android 依赖。** `BinCore.java` 全是 static 方法，不 import 任何 `android.*`，所以能直接在桌面 JVM 上跑单测，不需要 Robolectric 也不需要真机。

**面板必须拿到焦点。** 这不是 bug 是特性——只有获得焦点的窗口读剪切板才不被系统拦。所以面板窗口不能加 `FLAG_NOT_FOCUSABLE`，只有气泡可以加。静态审查里专门有一条守着这个约束。

想自己构建、跑测试、看源码结构，见 [DEVELOPMENT.md](DEVELOPMENT.md)。

## 已知限制

- **既有功能只在 ColorOS 16 / Android 16 真机上验证过**；v2.10 新增界面风格和小米 / 澎湃厂商页面尚未在对应真机验收
- 点悬浮球会收起当前键盘（抢焦点的必然代价）
- 面板宽度最多到屏幕宽度的 90%，窄屏上按钮仍可能显得挤
- 不支持自动监听，必须手动点
- 剪切板内容超过 64KB 会被系统截断（复制超大结果时会主动截到 50 万字符）
- **从剪切板读入最多取前 5 万字符**，超出会明确提示被截断（不提示就默默只转前一段）；超过 2 万字符不再做方向自动识别，直接按「文字 → 二进制」处理，避免在主线程上白跑正则和解码
- Base64 判定靠「解出来像不像正文」打分，极端短串（如 4 个字母）仍可能判错；拿不准时手动切方向
- **摩斯码里中文靠电码表**：内置 7078 个汉字（UCD `kMainlandTelegraph`）。表外的生僻字、emoji、日文转成 `?` 占位，不保证能还原原字；反向解出来一律大写，原来的大小写找不回来
- 摩斯码单次最多 2000 字符（一个字符最多 6 个符号，再长就没必要在手机面板上看了）
- 转换历史只存最近 20 条、每条最多 120 字符（超长的点回来也只有前 120 字符，胶囊上会带省略号），且是明文存在 App 私有目录里，不加密
- 方向按钮停在「自动」时按内容实时判定；一旦手动选了「文→码」或「码→文」，就一直按你选的来，直到点回「自动」
- **检查更新要求仓库是公开的**：镜像（jsDelivr / gh-proxy）只能匿名读公开仓库
- 检查更新依赖「发版就同步 `version.json` + `dist/BinFloater.apk` 并打 tag」的纪律；忘了提交这两个文件，别人读到的还是上一版
- 镜像走的是 jsDelivr（对分支有约 12 小时缓存）和 gh-proxy；国内实测可通，但镜像本身偶尔抽风，自动检查失败时静默、手动检查才报原因
- **装在手机上的旧版本（v2.5 及以前）检查更新仍然直连 `github.com`**，没有梯子查不到 —— 需要手动装一次 v2.6，之后才走镜像
